# Password Strength Checker

## Overview
This project is a Password Strength Checker developed using Python, Machine Learning, HTML, and CSS. It predicts whether a password is Weak, Medium, or Strong.

## Technologies Used
- Python
- Machine Learning
- HTML
- CSS

## Features
- Password strength prediction
- User-friendly interface
- Machine Learning-based analysis

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Run `app.py`.
4. Open the application in your browser.
